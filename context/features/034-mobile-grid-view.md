# 휴대폰 그리드 보기 개선

## 식별자와 상태

- 스펙 ID: `034-mobile-grid-view`
- 상태: 검토 중 — 구현·로컬 검증 완료. 남은 것: 미리보기 배포 `@smoke` 2회, 안드로이드 실기기(MOBILE_CHECKLIST 11절, 사용자), 아이폰 Safari(공개 배포 전 팀원)
- 문서 작성만으로 구현이나 검증을 완료 처리하지 않는다.

## 근거

- 비즈니스 규칙: TIME-09-01(날짜 단위 선택), TIME-10-04(드래그 중 폴링 반영 보류), TIME-08-01(지난 칸) — `docs/specs/rules/TIME.md`
- 화면: 시안 이미지 없음(사용자 결정). 아래 「확정 화면」이 기준
- API·ERD: 변경 없음(TIME-API-01·02 그대로). 저장 데이터는 30분 칸 그대로
- 관련 결정: R-38(033 휴대폰 드래그 선택 — 「끌다가 화면 끝 자동 스크롤 넣지 않음」을 이 기능이 바꿈), 이 기능의 결정 **R-39**
- 출처: 033 안드로이드 실기기 확인(2026-11-15, MOBILE_CHECKLIST 10절)의 불편 세 가지

## 사용자와 문제

휴대폰(한 그리드만 보이는 좁은 화면)에서 ① 날짜가 2개만 보여 옆으로 많이 밀어야 하고, ② 9:00~24:00을 30분 단위로 보면 세로로 너무 길고, ③ 드래그하다 화면 끝에 가도 스크롤되지 않는다.

## 확정 화면 (2026-11-15, 사용자 지시)

적용 범위: 휴대폰 = 지금 한 그리드로 보이는 좁은 화면(Tailwind `lg` 64rem 미만, 「내 시간」·「모두의 시간」 탭이 있는 화면). 데스크톱(두 그리드 나란히)은 그대로다. 단 자동 스크롤(4)은 데스크톱 마우스 드래그에도 넣는다.

그리드 위 구성(위에서 아래):

```text
[ 내 시간 | 모두의 시간 ]                     ← 탭(지금 그대로)
[30분|1시간|2시간]        [드래그로 선택 꺼짐] ← 도구 줄(「내 시간」만, 드래그 버튼은 터치 기기·입력 가능일 때)
[◀]   11/16 (월) – 11/19 (목)   [▶]           ← 날짜 넘기기 줄(두 탭 공통 구간)
┌────┬──────┬──────┬──────┬──────┐
│    │11/16 │11/17 │11/18 │11/19 │           ← 4일이 폭에 딱 맞음, 가로 스크롤 없음
│09:00│ ✓   │ 2/4  │      │  —   │           ← 2시간 보기 예
...
[입력 중 · 제출 전   3일 · 총 5시간]  [?] [가능 시간 제출]   ← 제출 바, 「?」로 범례·사용법 펼침
```

### 1. 날짜 4일씩 넘기기

- 그리드에는 4일만, 칸 폭은 4일이 그리드 폭에 딱 맞게. 옆으로 미는 스크롤 없음
- 날짜 넘기기 줄 「◀ 11/16 (월) – 11/19 (목) ▶」. 구간은 약속 날짜 범위의 첫날부터 4일씩 끊는다
- 처음 열면 오늘(지나지 않은 첫 날)이 든 구간. 첫 구간에서는 ◀, 마지막 구간에서는 ▶를 흐리게(누를 수 없음)
- 「내 시간」과 「모두의 시간」이 같은 구간을 쓴다(탭을 바꿔도 보던 구간 유지)

### 2. 내 시간의 표시 단위 (30분 / 1시간 / 2시간)

- 「내 시간」에만 세 칸짜리 단위 선택. 기본 30분. 「모두의 시간」은 30분 그대로(묶은 인원 수는 오해를 부름)
- 저장은 30분 칸 그대로. 1시간·2시간은 30분 칸 2개·4개를 한 칸으로 묶어 보여 줄 뿐. 묶음은 하루 시작 시각부터 끊고 끝에 남는 칸은 짧은 묶음
- 묶은 칸 상태(지난 칸은 셈에서 뺌): 전부 선택 = 파란 칸 + 체크 / 일부 선택 = 연한 파랑 + 파란 테두리 + "n/m"(m = 지나지 않은 칸 수) / 선택 없음 = 빈칸 / 전부 지난 시간 = 회색 + "—"
- 30분 보기에서도 선택된 칸에 체크 표시(색만으로 구분하지 않음)
- 묶은 칸 누름: 전부 선택이면 안의 칸 전부 해제, 아니면 지나지 않은 칸 전부 선택. 드래그 모드에서 끌면 같은 규칙을 묶은 칸 단위 사각형으로(첫 칸의 반대 상태)
- 단위를 바꿔도 선택 내용은 그대로

### 3. 도구 줄 정리

- 그리드 위: 탭 → (단위 선택 + 「드래그로 선택」 한 줄) → 날짜 넘기기 줄. 드래그 버튼은 글자로 켜짐·꺼짐(033 버튼을 이 줄로 옮김)
- 휴대폰에서는 섹션 제목 「내 가능 시간」 줄을 뺀다(탭 「내 시간」과 겹침, 그리드 공간 — 보고 확인 뒤 사용자 결정). 데스크톱은 그대로
- 휴대폰에서 그리드 위 범례(가능·불가능·지난 시간)는 제출 바 옆 「?」를 눌렀을 때만 펼침
- 날짜 머리글로 하루 전체를 선택·해제하면 화면 아래에 약 3초 「11/17 (화) 전체 선택됨 · 되돌리기」. 되돌리기를 누르면 그날을 직전 상태로

### 4. 드래그 중 자동 스크롤

- 드래그 중 손가락(마우스)이 화면 위·아래 끝 가까이(약 48px)에 가면 페이지를 자동 스크롤, 끝에 가까울수록 빠르게. 스크롤되는 동안에도 손가락 아래 칸이 계속 선택에 반영. 휴대폰 선택 모드와 데스크톱 마우스 드래그 모두
- 가로 자동 스크롤은 넣지 않음(휴대폰은 4일씩 넘김)
