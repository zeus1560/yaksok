# MVP 범위 (2026-10-30 확정)

> 근거: PRD 4장·8장. 상세는 [PRD.md](./PRD.md).
> 추출일: 2026-10-30

## 한 줄 정의

MVP는 **"약속 생성 → 참여자 등록 → 시간 조율 → 후보 추천 → 방장 확정"까지 완결**된 플로우다. 그 이상은 범위가 아니다.

## 범위 내 (MVP)

- 초대 링크 발급 — 카카오톡 챗봇과 웹 「새 약속 만들기」 병행 (챗봇 연결 후에도 웹 발급 유지)
- 링크 기반 비회원 참여 (닉네임 + 숫자 4자리 PIN, 약속별 세션)
- 방장 등록과 약속 설정 (정원 · 날짜 범위 · 하루 시간 범위 · 소요 시간 · 마감 시각)
- 30분 슬롯 단위 가능 시간 제출·재제출
- 시간 후보 자동 계산과 **방장 수동 확정**
- 약속 상태 관리 (draft / collecting / closed / confirmed / cancelled) 및 재설정 · 재조율 · 취소
- 참여자 탈퇴 · 내보내기 · 방장 자동 승계
- 확정 결과 링크 공유

## 범위 외 (MVP 이후)

> **카카오 로그인 · 톡캘린더 · 위치/중간지점 · 장소 추천/투표는 전부 여기에 속한다.** 2026-09-18 노트에서 로그인·톡캘린더를 MVP로 옮겼던 결정은 2026-10-30 개정으로 취소되었다. 이 항목들은 비즈니스 규칙 DB · ERD · API 명세서에 **아직 설계가 없다.**

- **카카오 간편 로그인(회원)** → ERD 스키마 확장 선행 필요
- **톡캘린더 자동 등록** → 회원 구조 선행 필요
- **위치 입력 및 중간지점 계산(centroid)**
- **장소 추천(네이버지도, 카테고리 필터)과 장소 투표·확정** → **서비스 핵심 가치와 직결**
- 대중교통 기반 정밀 중간지점 계산(ODsay)
- 약속 하루 전 알림(알림톡) → 사업자 등록·템플릿 심사 이슈로 보류
- 확정 내용 챗봇 자동 발송
- 가능/애매 3단계 시간 입력
- AI 기반 장소 큐레이션(OpenAI)
- 로그인 유저 한정 채팅 기능
- 예약 연동(제휴)
- 반복 모임 이력 관리, 정산 기능
- 길찾기

## 핵심 제약값

> 📌 아래 값은 모두 **비즈니스 규칙 DB**를 기준으로 한다. 구현 중 다른 문서와 충돌하면 **비즈니스 규칙을 우선**한다.

| 항목 | 값 | 근거 규칙 ID |
| --- | --- | --- |
| 기준 시간대 | `Asia/Seoul` 고정 | TIME-01-01 |
| 가능 시간 입력 단위 | 30분 슬롯 | TIME-06-01 |
| 약속 소요 시간 | 최소 30분, 30분 단위, 기본값 2시간. 하루 선택 범위보다 길 수 없음 | TIME-06-02 |
| 하루 선택 시간 | 기본 09:00~24:00. 방장이 00:00~24:00 안에서 30분 단위로 변경 | TIME-05-02 |
| 날짜 범위 | 종료일은 한국 시간 오늘부터 3개월 이내, 달력의 월 단위로 계산 | STATE-03-01 |
| 모집 시작 필수값 | 정원 · 날짜 범위 · 하루 시간 범위 · 소요 시간 · 응답 마감 시각 | STATE-03-01 |
| 마감 판정 | 서버 시각 기준, 현재 ≥ 마감 시각이면 마감 | STATE-05-01, TIME-15-02 |
| 전원 제출 시 자동 마감 | 하지 않음 | STATE-05-03 |
| 후보 최소 인원 | 약속 길이 전체를 연속 참석 가능한 인원 2명 이상 | RESULT-03-01, RESULT-04-01 |
| 후보 정렬·표시 | 가능 인원 많은 순 → 시작 시각 빠른 순, 상위 5개 기본 표시 | RESULT-06-01, RESULT-06-02, RESULT-07-01 |
| 확정 권한 | 방장만. 자동 확정 없음 | RESULT-11-01 |
| 닉네임 | 2~12자, 앞뒤 공백 제거 | MEMBER-05-01 |
| PIN | 숫자 4자리 | MEMBER-06-01 |
| 초대 링크 만료 | 기준 시각 7일 뒤. 기준: 확정이면 약속 시작 시각, 미확정이면 응답 마감 시각, 방장 등록 전(또는 마감 없는 draft)이면 링크 발급 시각 | MEMBER-01-02 |
| 미완성 초안(draft) 만료 | 방장 등록 후 10분, 2분 전 안내 | STATE-02-02 |
| 자동 로그인 유지 | 약속 마감 후 7일, 약속별 쿠키 | MEMBER-06-03 |

## 에이전트 주의사항

- **미결 항목은 임의로 결정하지 말 것.**
