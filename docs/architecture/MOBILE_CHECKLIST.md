- [ ] PC 브라우저(Vercel에 로그인된 것)를 하나 준비합니다. 8절에서 PC와 휴대폰을 나란히 봅니다

### 휴대폰에서 미리보기 주소 여는 방법

미리보기 주소는 Vercel 로그인 보호(Deployment Protection)가 걸려 있어 그냥 열면 Vercel 로그인 화면이 나옵니다. 둘 중 하나로 엽니다.

**방법 A — 휴대폰 브라우저에서 Vercel 로그인 (본인 휴대폰, 권장)**

1. 배포 고유 주소를 휴대폰으로 보냅니다(나에게 보내는 카카오톡·메모·메일)
2. 주소를 **Safari(아이폰)·Chrome(안드로이드)에서 직접** 엽니다. 카카오톡 안에서 눌러 열린 화면(인앱 브라우저)은 로그인 상태가 따로라 쓰지 않습니다 — 주소를 길게 눌러 복사한 뒤 브라우저 주소창에 붙여 넣습니다
3. Vercel 로그인 화면에서 **Continue with GitHub** → `zeus1560` 계정으로 로그인합니다(GitHub 2단계 인증이 있으면 인증 앱이 필요합니다)
4. 로그인이 끝나면 미리보기 화면으로 돌아옵니다. 이미 로그인된 브라우저는 바로 열립니다
5. 다른 브라우저·다른 휴대폰은 각각 한 번씩 로그인합니다

**방법 B — 배포 화면의 Share 링크 (로그인할 수 없는 휴대폰, 빌린 휴대폰)**

1. PC에서 Vercel 대시보드 → 프로젝트 → **Deployments** → 확인할 **Preview 배포**를 엽니다
2. 배포 화면의 **Share** → 드롭다운에서 **Anyone with the link**를 고르고 링크를 복사합니다
3. 그 링크를 휴대폰으로 보내 브라우저에서 엽니다. 로그인 없이 열립니다
4. **끝나면 같은 드롭다운을 Only people with access로 되돌립니다**

- Hobby 플랜은 **공유 링크를 계정 전체에서 1개만** 만들 수 있습니다. 새 배포를 확인하려면 앞의 것을 끄고 다시 만듭니다
- 링크를 아는 사람은 누구나 그 배포(미리보기 DB의 약속 포함)를 열 수 있습니다. 공개된 곳에 올리지 않습니다
- 공유 링크로 연 브라우저에서 앱이 만든 초대 링크(`/p/…`)까지 그대로 열리는지는 0-4에서 확인합니다. 다시 로그인 화면이 나오면 그 휴대폰은 방법 A로 합니다

> 보호 우회 비밀값(`VERCEL_AUTOMATION_BYPASS_SECRET`)은 자동 테스트용입니다. 휴대폰 주소에 붙여 쓰지 않습니다.
