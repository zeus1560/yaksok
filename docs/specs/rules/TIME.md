## TIME-05-02 — 자정 넘김

## TIME-10-02 — 제출의 의미

- **검토 질문**: 저장과 별개로 제출을 완료하면 어떤 의미와 효과가 생기는가?
- **상태**: 유지
- **메모**: Notion의 `규칙 ID` 속성 값에 불필요한 `<p>` 마크업과 공백이 섞여 있다(`<p>TIME-10-02 </p>`).
- **결정**:
  - **상태(본문)**: 확정
  - **규칙**: 제출은 본인 응답 입력을 마쳤다는 표시다. 제출 전에 선택한 슬롯은 본인 브라우저 화면에만 표시되고 서버에는 저장되지 않는다. 제출하면 응답이 서버에 저장되어 다른 참여자 화면에도 표시되며, 제출한 참여자의 응답만 집계와 후보 계산에 반영한다.
  - **예시**: 처음 제출하기 전에 슬롯을 선택만 하고 제출하지 않으면 본인 화면에서만 선택 상태가 보이고, 다른 참여자에게는 불가으로 표시된다. 제출 버튼을 누르면 그때부터 다른 참여자 화면에도 선택한 슬롯이 반영된다.
  - 제출 전 선택은 브라우저에 임시 보관되어 새로고침하거나 다시 접속해도 유지된다. 단, 다른 기기나 다른 브라우저에서 접속하면 보이지 않는다. 제출하면 임시 보관 내용은 삭제된다.
  - **추가 결정**: 제출하면 그 참여자의 슬롯 전체를 한 번에 교체한다. 제출하면 제출 시각을 기록한다. 제출 전 임시 보관은 localStorage를 사용하며, 키는 약속ID와 참여자ID 조합으로 한다. 제출은 POST(또는 PUT) 요청으로 서버에 저장하고, 저장에 성공하면 본인 화면을 즉시 최신 상태로 갱신한다.
- **원본**: https://app.notion.com/p/8837085f318282f687398101a151c354
