## 0. 읽는 법

- **Figma 자료:** `docs/design/figma/screens/`(화면 PNG 1x, 1200×940), `docs/design/figma/components/`(컴포넌트 5페이지). Figma MCP는 쓰지 않았다. 색·크기는 PNG 픽셀을 직접 재서 얻은 값이다(1x라 1픽셀 = 1px, 모서리 반경은 안티에일리어싱으로 잰 근삿값).
- **우리 화면:** `scripts/verify/029-figma-capture.mjs`(Git 제외)로 dev 서버에서 같은 상태를 만들어 찍었다. 데스크톱 1200px, 23만 390×844. 나란히 보기용 사본은 `docs/design/compare/figma/`·`docs/design/compare/ours/`(Git 제외)에 있다. 촬영본 왼쪽 아래 "N" 원은 Next.js 개발 표시라 비교 대상이 아니다.
- **분류**
  - **시각:** 색·글꼴 크기·간격·모서리·그림자·문구처럼 값만 맞추면 되는 것
  - **구성:** 요소 위치·배치·빠진 요소, 컨트롤 종류가 다른 것
  - **규칙 충돌:** Figma가 확정 규칙·결정과 다른 것. 규칙을 따르므로 **고치지 않는다**(근거 표시)
  - **미구현:** Figma에만 있는 기능
- **크기 표시:** 🔶 = 고치려면 큰 작업(여러 화면·상태 로직·새 공통 컴포넌트가 바뀜). 표시가 없으면 한 컴포넌트 안의 클래스·문구 수정이다.
- 같은 차이가 여러 화면에 나오면 처음 나온 항목만 세고, 뒤에서는 "→ 항목 ID"로 가리킨다.

## 5. 13~16 월·주 이동 vs 지금 가로 스크롤

### Figma 방식

- 그리드는 한 주(7일) 표. 툴바 ‹ / ›는 7일씩 이동, "오늘"은 오늘이 있는 주로, 주 제목("2026년 10월 · 4–10일")은 보고 있는 주 기준.
- 월 제목(툴바 또는 사이드바 미니 달력)을 누르면 "이동할 날짜 선택" 팝업(월 달력, ‹ › 월 이동). 범위 밖 달은 둘러볼 수만 있고 날짜는 회색으로 고를 수 없음. 날짜를 누르면 그 날짜가 있는 주로 이동.
- 다른 주로 옮겨도 선택은 그대로(16).
- 모바일(23)도 주 단위 + 가로 스크롤("주간 그리드는 가로 스크롤") + ‹ ›.

### 지금 방식

- 설정 범위의 모든 날짜(최대 약 3개월, R-07)를 한 그리드에 놓고 가로 스크롤(`grid-frame.tsx`, 시간 열 고정). 데스크톱은 "내"·"모두의" 두 그리드가 각자 스크롤.
- 날짜 머리글을 누르면 그날 전체 선택/해제(TIME-09-01). 드래그는 범위 안 어느 날짜든 한 번에 사각형으로 가능.
